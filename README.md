Main Switch Panel-Level Connection.

 (Professional Installation Only)
 1. Licensed Electrician Required: 
   This installation type must be handled strictly by a licensed electrical professional.
 2. Isolate Primary Power: 
   The primary utility service breaker must be switched off and checked for a complete zero-energy state using calibrated diagnostic tools before opening the panel.
 3. Series Integration: 
   Mount FluxGuard-Pro15k inside a secure, non-conductive, ventilated enclosure next to the main panel. Slice the main Hot (Live) feed coming out of your main disconnect switch, connecting the input side to AC Pin 1 of the  FluxGuard-Pro15k and the output side (leading to individual branch circuit breakers) to AC Pin 2. 
4. Bypass Neutral and Ground: 
   Ensure the system Neutral and Ground lines completely bypass the filter circuit and remain firmly bonded to their native distribution busbars. This maintains the structural integrity of your house/small establishment grounding paths.

5. Mandatory Protective Disclaimers (The Fine Print)
⚡ Surge Disclaimer:
   "FluxGuard-Pro15k is a power quality conditioning device designed to stabilize core flux and eliminate DC offsets. It is not a surge protector or lightning arrestor. 
   For lightning protection, pair FluxGuard-Pro15k with a certified Type 2 Whole-House Surge Protective Device (SPD) at your main breaker panel."
